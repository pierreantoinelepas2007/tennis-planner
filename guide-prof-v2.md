# Guide rapide — Planificateur de l'école de tennis

## Deux liens à connaître

**Lien à partager avec les familles (formulaire d'inscription uniquement, sans mot de passe) :**
https://tennis-planner-llou.onrender.com/?tab=formulaire

**Lien pour vous (accès complet à la gestion), avec mot de passe :**
https://tennis-planner-llou.onrender.com

Le mot de passe de gestion vous a été communiqué séparément.

Petite chose à savoir : si personne n'a utilisé le site depuis un moment, il peut mettre 30 à 60 secondes à s'ouvrir la première fois. C'est normal, pas un bug — patientez juste un peu au premier chargement.

## Les onglets (après connexion avec le mot de passe)

- **Accueil** : résumé rapide de la marche à suivre
- **Formulaire** : identique à ce que les familles voient, pour tester ou inscrire quelqu'un vous-même
- **Participants** : tous les inscrits. C'est ici que vous notez le niveau (étoiles) de chacun, une fois que vous les avez vus jouer
- **Professeurs** / **Terrains** : déjà remplis avec les infos du club — à modifier seulement si les horaires changent
- **Planning** : génère et ajuste le planning automatiquement
- **Disponibilités restantes** : un calendrier qui montre les créneaux encore libres (par professeur, en couleur) — cliquez sur un créneau libre pour y placer directement quelqu'un qui n'a pas encore de cours
- **Vue par prof** : le planning filtré par professeur, à imprimer ou exporter

## Comment ça marche, dans l'ordre

1. **Partagez le lien du formulaire** (celui du haut) sur le groupe WhatsApp, en demandant à chacun d'aller remplir une inscription par cours souhaité (une personne qui veut 2 cours par semaine remplit le formulaire 2 fois — un bouton "Ajouter un autre cours" apparaît après la première validation pour faciliter ça)
2. Une fois les inscriptions arrivées, allez dans **Participants** et donnez une note en étoiles (1 à 5) à chaque personne qui n'a pas de classement officiel — c'est vous qui décidez, en fonction de ce que vous connaissez du niveau de jeu. Si quelqu'un a déjà un classement officiel (C30.4, B0, etc.), ce n'est pas nécessaire de mettre des étoiles, le site s'en sert directement.
3. Allez dans **Planning**, cliquez sur **"Générer une proposition"** — le site propose automatiquement un planning
4. **Vérifiez et ajustez** : le site peut se tromper ou faire des choix imparfaits, c'est normal, c'est à vous de trancher en dernier
5. Une fois un cours qui vous convient, cliquez sur le petit **cadenas** 🔒 pour le "verrouiller" — comme ça, si vous régénérez le planning plus tard, ce cours-là ne bougera plus, et les personnes qui y sont déjà ne seront plus proposées ailleurs
6. Pour les participants qui restent sans cours, allez dans **Disponibilités restantes** : vous verrez leurs disponibilités affichées, et vous pourrez cliquer directement sur un créneau libre compatible pour les y placer
7. Allez dans **Vue par prof** pour voir/exporter le planning de chaque professeur

## Ce que veulent dire les alertes

- **"Participants non casés"** : des personnes qui n'ont pas pu être placées dans le planning proposé — le site ne rejette jamais une info discrètement, il vous dit toujours qui n'a pas de créneau, à vous d'ajuster à la main (voir "Disponibilités restantes")
- **"À trancher"** : plusieurs personnes étaient possibles sur un même cours, le site en a choisi une — vous pouvez changer si vous préférez quelqu'un d'autre
- **"Horaires différents"** : deux personnes qui avaient demandé le même horaire n'ont pas pu être alignées — à ajuster si possible

## Pour modifier un cours à la main

Sur chaque cours du planning, vous pouvez changer le terrain, le professeur, ajouter ou retirer quelqu'un directement avec les menus déroulants — pas besoin de tout régénérer pour un petit ajustement.

## Un point important sur la sécurité

Le lien du **formulaire** peut être partagé largement (c'est prévu, les familles en ont besoin). Le lien complet avec le mot de passe, en revanche, ne doit être connu que par vous et moi — ne le transmettez pas à d'autres personnes du club sans m'en parler d'abord.
