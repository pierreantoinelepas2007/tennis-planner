# Guide rapide — Planificateur de l'école de tennis

Lien du site : **https://tennis-planner-llou.onrender.com**

Petite chose à savoir : si personne n'a utilisé le site depuis un moment, il peut mettre 30 à 60 secondes à s'ouvrir la première fois. C'est normal, pas un bug — patientez juste un peu au premier chargement.

## Les onglets

- **Accueil** : résumé rapide de la marche à suivre
- **Formulaire** : c'est le lien à partager aux familles/joueurs pour qu'ils s'inscrivent
- **Participants** : tous les inscrits. C'est ici que vous notez le niveau (étoiles) de chacun, une fois que vous les avez vus jouer
- **Professeurs** / **Terrains** : déjà remplis avec les infos du club — à modifier seulement si les horaires changent
- **Planning** : génère et ajuste le planning
- **Vue par prof** : le planning filtré par professeur, à imprimer ou exporter

## Comment ça marche, dans l'ordre

1. **Partagez le lien du site** sur le groupe WhatsApp, en demandant à chacun d'aller dans l'onglet *Formulaire* pour chaque cours souhaité (une personne qui veut 2 cours par semaine remplit le formulaire 2 fois)
2. Une fois les inscriptions arrivées, allez dans **Participants** et donnez une note en étoiles (1 à 5) à chaque personne — c'est vous qui décidez, en fonction de ce que vous connaissez du niveau de jeu
3. Allez dans **Planning**, cliquez sur **"Générer une proposition"** — le site propose automatiquement un planning
4. **Vérifiez et ajustez** : le site peut se tromper ou faire des choix imparfaits, c'est normal, c'est à vous de trancher en dernier
5. Une fois un cours qui vous convient, cliquez sur le petit **cadenas** 🔒 pour le "verrouiller" — comme ça, si vous régénérez le planning plus tard, ce cours-là ne bougera plus
6. Allez dans **Vue par prof** pour voir/exporter le planning de chaque professeur

## Ce que veulent dire les alertes

- **"Élèves non casés"** : des personnes qui n'ont pas pu être placées dans le planning proposé — le site ne rejette jamais une info discrètement, il vous dit toujours qui n'a pas de créneau, à vous d'ajuster à la main
- **"À trancher"** : plusieurs personnes étaient possibles sur un même cours, le site en a choisi une — vous pouvez changer si vous préférez quelqu'un d'autre
- **"Horaires différents"** : deux personnes qui voulaient le même horaire n'ont pas pu être alignées — à ajuster si possible

## Pour modifier un cours à la main

Sur chaque cours du planning, vous pouvez changer le terrain, le professeur, ajouter ou retirer quelqu'un directement avec les menus déroulants — pas besoin de tout régénérer pour un petit ajustement.

## Un point important

Le lien du site n'est pas protégé par mot de passe pour l'instant — évitez de le partager plus largement que nécessaire (le groupe des familles pour le formulaire, c'est prévu et normal ; pas au-delà).
